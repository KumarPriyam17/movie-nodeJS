───────────────────────────────────────────────────────────────
Problem: MongoDB connection error
Solution: Start mongod or set MONGODB_URI in .env

Problem: Port 5000 already in use
Solution: Change PORT in .env file

Problem: Movies not loading
Solution: Check MongoDB is running and connected

Problem: Blank page on http://localhost:5000
Solution: Open browser console (F12) for errors
